根目录为单一可执行项目：`src/main.cpp` 的 `wWinMain` 创建 `App` 单例，统一持有主窗口句柄、布局状态、字体/画刷资源与双缓冲缓存，并组合四个子模块——`webview`（WebView2 COM 封装）、`capture`（Cookie/Token 解析）、`settings`（配置持久化）、`logwriter`（结构化日志）。UI 层经历从原生 GDI 自绘到 WebView2 玻璃外壳的渐进迁移：`shell` 通过 postMessage 双向桥驱动业务，`theme` 集中语义调色板并生成 CSS 变量供 WebView2 起始页消费，消除原生与 Web 双配色割裂；业务子系统保持不变，仅通过回调接口被 shell 调用。资源文件经 `res/app.rc` + windres 编译为 `app.res` 后静态链接进 exe，测试端点位于 `test/serve.py` + `login.html`。
