模块由 shell.h 声明的 `shell::State` 结构体作为运行态快照，以及两个对外 API：`Build(const State&)` 生成整页 HTML（含内联 CSS 变量、DOM 结构与 JS 事件桥），`StateJs(const State&)` 生成增量推送脚本 `window.CG.state({...})`。

- 视图拓扑：shell WebView 铺满客户区绘制环境光斑与各视图；被导航的第三方站点由独立的 Content WebView（App::webview_）承载，按 shell 上报的 `#webhole` 矩形定位并覆盖其上，二者是主窗口的兄弟子窗口，Content 在 Z 序更高。
- 双向桥：JS→host 统一走 `window.chrome.webview.postMessage(JSON)`，信封格式 `{t:"...",...}`（如 open/reload/cap/page/win/cfg/layout/ready）；host→JS 调用 `ExecuteScript("window.CG.state({...})")` 增量更新 DOM。
- 安全边界：Cookie/Token 值绝不进入 shell，仅传递计数与地址等元数据。
- 主题：所有颜色通过 `theme::StartPageCss()` 注入的同源 CSS 变量（--glass, --ambient-a/b/c, --accent-* 等）实现 glassmorphism 配色，支持 light/dark 双模式。
- 依赖方向：shell → theme/util/json/settings；不反向依赖 capture/logwriter/webview 等业务子系统。
