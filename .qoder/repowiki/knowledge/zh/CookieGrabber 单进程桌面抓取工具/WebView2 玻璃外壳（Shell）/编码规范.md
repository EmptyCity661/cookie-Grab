- JS 到宿主的消息统一封装为 `{t: "动作名", ...}` 信封，通过 `window.chrome.webview.postMessage(JSON.stringify(o))` 发送，宿主侧按 t 字段分派处理。
- 宿主到 JS 的状态更新统一通过 `window.CG.state({...})` 增量推送，由 `StateObj` 序列化的字段集驱动，避免整页重建。
- HTML 字符串中嵌入的用户可控文本一律经 `HtmlEsc` 或 `mjson::Escape` 转义后再拼入模板，防止 XSS。
- 宽字符（std::wstring）在写入 HTML/JSON 前统一经 `util::WideToUtf8` 转为 UTF-8 字节串。
- CSS 样式全部基于 `theme::Current()` 返回的 Palette 变量（--glass, --ambient-*, --accent-* 等）着色，禁止硬编码颜色字面量。
