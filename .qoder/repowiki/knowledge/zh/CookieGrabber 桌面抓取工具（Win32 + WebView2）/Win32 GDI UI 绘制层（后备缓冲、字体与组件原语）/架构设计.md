模块以 `src/ui.h` 暴露三类抽象，依赖方向单向向外：
- `Painter`：封装 top-down 32bpp DIB 段后备缓冲，通过 `Ensure/Destroy/BlitTo` 管理 HDC/HBITMAP/bits_ 生命周期，避免高频 resize/滚动时旧帧残影。
- `Fonts`：按 DPI 批量创建 Segoe UI / Segoe Fluent Icons 字体句柄，`Build(dpi)` 一次性构建、`Release()` 统一销毁，DPI 变化时整体重建；图标字体优先 Segoe Fluent Icons，回退 Segoe MDL2 Assets。
- `draw::` 命名空间：基础原语（`Rect/RoundRect/Card/HLine/VLine/Glyph/FocusRing/Text/Measure/WrapText`）与高级组件（`Button/Toggle/Chip/Scrollbar/Dot`），所有颜色经 `Mix` 混合，所有尺寸经 `MulDiv(..., dpi, 96)` 换算。
仅依赖 `windows.h` 与同目录的 `theme.h`（`Palette`、`scale::*` 常量），不反向被 theme 依赖；上层窗口逻辑通过 `Painter::DC()` 获取 HDC 调用 draw 函数完成一帧绘制后 `BlitTo` 到窗口 DC。
