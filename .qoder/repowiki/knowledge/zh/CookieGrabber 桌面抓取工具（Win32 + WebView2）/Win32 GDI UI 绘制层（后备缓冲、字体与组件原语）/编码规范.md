- 所有物理尺寸通过 `MulDiv(px, dpi, 96)` 在 96 DPI 基准上缩放，保证 DPI 感知渲染一致。
- GDI 对象（HBRUSH/HPEN/HGDIOBJ）采用 SelectObject 后立即 SelectObject 还原并 DeleteObject 释放的成对模式，避免资源泄漏。
- 文字排版统一走内部 `DrawWith` 辅助：设置 TRANSPARENT 背景、保存/恢复字体与前景色，并按 flags 自动计算垂直居中矩形再 DrawTextW。
- 组件函数签名统一形参顺序 `(HDC dc, RECT rc, ..., const Fonts& f, const Palette& p, int dpi)`，将样式与主题参数放在末尾。
- 颜色选择通过 `draw::Mix` 在 `Palette` 成员间插值，派生态效果（悬停/投影等）禁止直接硬编码 RGB 值。
