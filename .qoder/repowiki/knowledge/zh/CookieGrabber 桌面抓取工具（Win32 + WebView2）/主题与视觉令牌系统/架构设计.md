模块由 `theme.h`（接口/数据定义）与 `theme.cpp`（实现）组成，对外暴露 `theme::Current()`、`Resolve(bool)`、`DetectDarkMode()`、`StartPageCss()`、`Hex(COLORREF)` 五个函数。
- 核心数据结构为 `Palette`（语义化命名的 `COLORREF` 字段：canvas/surface/accent/text 等）与 `scale` 命名空间下的 96dpi 逻辑像素常量（半径、间距、字号、控件尺寸），所有绘制在调用 `App::S()` 前按此基准缩放。
- 运行时通过静态全局 `g_pal` 持有当前主题，`MakeLight()` / `MakeDark()` 工厂构造浅色/深色两套完整调色板，`Resolve()` 切换。
- 深色模式检测直接读取注册表 `HKCU\...\Themes\Personalize\AppsUseLightTheme`。
- `StartPageCss()` 将当前 `Palette` + `scale` 常量序列化为 CSS 自定义属性（`:root { --canvas, --surface, --accent, --radius-card ... }`），供 WebView2 起始页消费，从而保证原生绘制与 Web 渲染同源。
- 依赖方向单向：本模块不反向依赖 UI 层，仅被原生绘制与 WebView2 初始化代码引用。
