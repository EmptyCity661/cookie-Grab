### Cookie 抓取工具
- 定义：本项目所实现的桌面应用，面向 Windows 平台，通过内嵌 WebView2 打开任意网站，自动扫描 Cookie、localStorage/sessionStorage 以及请求头/响应体中的 Token（如 JWT、Authorization 等），并将结果写入日志供用户导出。
- 别名：cookie抓取工具3.0、Cookie/Token 抓取工具

### Token 抓取
- 定义：区别于 Cookie 抓取（mask=1）的独立模式（mask=2），仅扫描 localStorage/sessionStorage 中键名匹配 token/jwt 的值，以及 fetch/XMLHttpRequest 请求头中包含 authorization、x-token、x-auth-token、x-access-token、x-session-token、x-jwt、proxy-authorization 等字段的值，以及 JSON 响应体中同名字段，不读取 Cookie。
- 别名：token 抓取、Token 捕获

### Cookie 抓取
- 定义：通过 WebView2 的 `ICoreWebView2CookieManager::GetCookies` 异步枚举指定 URI 下的 Cookie，提取 name/value/domain/path/expires/httpOnly/secure/isSession/sameSite 后写入日志。
- 别名：cookie 抓取

### TokenHookScript
- 定义：注入到 WebView2 页面中的 JavaScript 钩子，负责拦截网络请求与存储变更，将发现的 token 以 `{type:'token', name, value, source, url}` 格式经 `window.chrome.webview.postMessage` 上报给 C++ 层。
- 别名：token hook、JS 钩子

### 抓取掩码（capture mask）
- 定义：`CaptureManager` 用位标志表示本次要输出的内容：`1`=Cookie、`2`=Token；两者互不影响，可单独抓取，也可同时输出。
- 别名：mask、Cookie/Token 位标志

### 防抖合并
- 定义：短时间内的多次抓取请求不各自执行，而是按位或合并抓取范围（600ms 防抖 + 250ms 存储预扫描），避免后到的请求覆盖先到的结果。
- 别名：debounce、延迟步骤定时器

### 登录态变更检测
- 定义：每 1500ms 轮询一次 Cookie 快照并与上次比对，仅在发生变化（或手动触发）时才写日志，否则状态行提示“登录状态无变化”。
- 别名：轮询、PollTick

### 双缓冲绘制层（Painter）
- 定义：`src/ui.h` 的 `Painter` 类，用 32 位 top-down DIB 段作后备缓冲，一帧画完再 `BitBlt` 上屏；相比 `CreateCompatibleBitmap`，像素格式由本模块显式掌握，高频 resize/滚动不会出现旧帧残影。
- 别名：后备缓冲、memDC_

### 焦点提示（Focus Cue）
- 定义：应用自行跟踪的输入方式标志（`App::FocusCueOn()`）：鼠标按键一律收起，仅 Tab/方向键导航时圆角按钮才绘制内缩的圆角焦点环，以取代系统的 `DrawFocusRect`。
- 别名：focusCue_、键盘焦点环

### 设计令牌（Palette + scale）
- 定义：`src/theme.h` 集中定义的语义色集合（`canvas`/`surface`/`accent`/`text` 等）与 96dpi 逻辑像素常量（半径、间距、字号、控件尺寸）；原生绘制与 WebView2 起始页 CSS 变量同源于此。
- 别名：主题、调色板、`theme::Current()`

### 起始页（Start Page）
- 定义：未打开任何网站时由应用自己渲染在本机页面上的欢迎/预设选择页，其样式与主题从同一套令牌生成（`StartPageCss()`）。
- 别名：startPageActive_、起始页 CSS

### 状态行（Status Row）
- 定义：浏览器页底部的自绘文本区，文本来自 `App::StatusText()`；它既是反馈区也是唯一的运行期错误通道，新状态会覆盖旧错误。
- 别名：statusText_、状态栏

### 单实例互斥体
- 定义：`App` 持有的命名 `HANDLE`（`singleInstance_`）；重复启动时只激活已有窗口并弹一次提示，避免两个进程争抢同一份 `settings.json` 与日志。
- 别名：singleInstance_
