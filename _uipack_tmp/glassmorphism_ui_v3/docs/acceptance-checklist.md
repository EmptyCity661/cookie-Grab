# UI 验收清单

- [ ] 主页面与设置页面共享相同的颜色、圆角、边框高光和阴影语言。
- [ ] 面板有半透明表面与 `backdrop-filter` 模糊；不支持时仍有可辨识的背景层级。
- [ ] 主操作、次级操作、禁用/选中状态有明确区别。
- [ ] 键盘 Tab 可聚焦可操作控件，开关可用键盘切换。
- [ ] 地址栏空值与非法 URL 有演示级校验反馈。
- [ ] 窗口在 1180px 和 780px 以下断点会调整布局。
- [ ] 设置页在深色与浅色玻璃主题切换时仍保持可读性。
- [ ] 原型的所有示例按钮均不会访问真实 Cookie、Token、认证状态或站点存储。
- [ ] 原生集成前先做事件映射、WebView2 安全审查与 DPI 回归测试。
