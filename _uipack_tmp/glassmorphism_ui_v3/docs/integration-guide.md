# WebView2 / Win32 接入建议（仅针对展示层）

## 建议方式

1. 将 `web/style.css` 作为界面主题基线，保留 CSS 变量，避免在每个组件里硬编码颜色。
2. 原生窗口背景、标题栏和页面内容分别处理。`backdrop-filter` 只模糊网页内的背景层，不会自动把 Win32 窗口后面的桌面内容变成毛玻璃。
3. 保留布局层与业务逻辑层边界：HTML 用于结构，CSS 负责材质与状态，JS 只处理演示层的导航、表单反馈和主题预览。
4. 接回原项目时，先对照控件 ID / 事件表，逐一确认现有事件来源、调用目标和返回状态，不要通过整页覆盖方式合并。
5. WebView2 消息桥接只应暴露明确且最小化的安全操作；不要把任意脚本执行、敏感会话数据或凭据内容放入页面日志、提示或调试输出。
6. 逐一测试 100%、125%、150% DPI 和窗口尺寸变化，重点看设置页表单、工具栏换行、底部状态栏和对话框边界。

## 注意

此资源包只提供通用浏览器工作台 UI 演示和主题样式，不包含对原应用敏感会话数据功能的接线代码，也不宣称与原生工程已经集成或编译通过。
