# Glass UI 3.0 — 主题参考

## 表面层级

1. **环境背景**：页面底层渐变，叠加低饱和度的蓝、紫、青色光斑。
2. **一级玻璃层**：侧边导航、工具栏、浏览器框架和底部状态栏；透明度中等，承担主要布局。
3. **二级玻璃层**：设置卡片、按钮和标签页；更轻的填充与略亮边缘，形成表面区分。
4. **凹入控件**：输入框、选择框使用较深的半透明底色和内阴影。
5. **强调层**：主按钮、选中导航和激活开关使用蓝色至靛蓝渐变，并辅以青色高光。

## 核心 CSS 变量

变量位于 `web/style.css` 的 `:root`：

- `--bg` / `--bg2`：背景基础色。
- `--panel` / `--panel-strong` / `--panel-soft`：不同级别玻璃表面。
- `--line` / `--line-hi`：常态描边与高光描边。
- `--text` / `--muted` / `--muted2`：文字层级。
- `--blue` / `--cyan` / `--violet`：主题强调色。
- `--blur`：玻璃模糊强度；设置页滑杆会在演示中动态调整。
- `--radius` / `--radius-sm`：主要与次级圆角。

## 调整建议

- 需要更通透：适度提高 `.glass-panel` 背景透明度，并保留边缘高光；不要只降低 opacity，否则文字和交互控件也会一起变淡。
- 需要更克制：减少背景光斑饱和度与 `box-shadow` 的扩散范围，保留 `backdrop-filter` 和细描边。
- 提高可读性：确保文字与半透明表面的对比度；玻璃效果不应应用到正文文字自身。
- 兼容模式：若宿主 WebView 对背景模糊支持不佳，保留现有渐变和边框，并将面板底色调高到更不透明。
