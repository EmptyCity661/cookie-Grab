# Glassmorphism UI 3.0 — 玻璃质感界面资源包

一套可独立预览的桌面应用 UI 原型，设计方向为 **深色玻璃 / 靛蓝与青色光效**，并提供浅色玻璃主题预览。与普通深色扁平卡片不同，本版用多层半透明表面、背景模糊、饱和度增强、边缘高光、内阴影、环境光斑和悬停光效构建玻璃材质。

## 快速预览

1. 解压 ZIP。
2. 打开 `web/index.html`。
3. 点击左侧「浏览器」「设置」「说明」切换页面。
4. 在「设置」页尝试「深色玻璃 / 浅色玻璃 / 跟随系统」、玻璃强度滑杆、开关、保存与恢复默认。

页面不依赖 CDN 或在线字体；样式、脚本和背景效果均为本地资源。建议使用最新 Microsoft Edge / Chromium 预览。

## 资源目录

- `web/index.html` — 浏览器工作台、设置页与说明页。
- `web/style.css` — 毛玻璃主题、响应式布局、焦点和悬停状态、浅色主题及降级样式。
- `web/app.js` — 独立演示交互：页面切换、示例网址校验、主题切换、玻璃强度调节、设置保存/重置与提示信息。
- `theme/tokens.json` — 可复用的颜色、模糊、阴影、圆角和间距设计令牌。
- `docs/theme-reference.md` — 材质层级、样式变量和调色建议。
- `docs/integration-guide.md` — 面向 Win32 / WebView2 的展示层接入建议。
- `docs/acceptance-checklist.md` — UI 验收与回归清单。

## 毛玻璃样式构成

- 背景：深海军蓝渐变与蓝、紫、青色柔光。
- 玻璃面板：半透明渐变底色 + `backdrop-filter: blur(...) saturate(...)`。
- 边缘：低对比度外描边与顶部内侧高光。
- 纵深：柔和投影、局部发光与不同透明度的表面分层。
- 操作状态：悬停、选中、键盘焦点、开关与成功提示采用一致的光效语言。
- 适配：主视图、设置视图、说明视图支持较窄窗口下的重排。

## 使用范围与限制

这是**独立 UI 原型/资源包**，并非已经编译完成的原生 3.0 应用。示例网址、配置项和状态均为演示数据；原型不会读取浏览器 Cookie、Token、登录态或真实站点存储，也未接入凭据提取、复制或导出操作。原生 C++ 项目尚未修改、集成或编译验证。

玻璃模糊在支持 `backdrop-filter` 的 Chromium / WebView2 中效果最好；不支持时会以半透明渐变和描边降级。将其接入现有项目之前，请先根据 `docs/integration-guide.md` 做控件与事件映射，避免整页覆盖业务代码。
