ABOUT / 03

界面说明

关于玻璃主题与本地演示原型。

✧

磨砂玻璃材质

通过半透明背景、背景模糊与细描边叠加出清透的玻璃层级。模糊效果会在支持 backdrop-filter 的浏览器中呈现。

▧

适配桌面窗口

布局使用 Grid 与 Flex 组合，主区与侧栏可随窗口宽度变化。WebView2 中可复用这些样式作为界面层参考。

◇

仅限演示数据

本原型不接入 Cookie、Token、登录状态或真实浏览器存储。所有文案、网址与设置仅用于展示 UI。
